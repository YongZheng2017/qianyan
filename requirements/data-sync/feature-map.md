# 数据同步管理功能地图

## 功能概述

数据同步管理模块是系统的数据采集核心模块，负责从外部数据源（如 Tushare）采集股票相关的各类数据，包括股票列表、日线行情、周线行情、月线行情等。该模块支持多数据源配置、定时自动同步、手动触发同步、同步参数自定义，并提供完整的同步日志和监控能力。

本模块服务于分析端的数据展示需求，是基本面分析和资金趋势分析的数据基础。

## 核心功能

### 1. 数据源管理（DS-001）
- 支持配置多个数据源（Tushare、AKShare 等）
- 数据源连接信息管理（API 地址、Token）
- 数据源连接测试
- 数据源启用/禁用状态管理

### 2. 同步任务管理（DS-002）
- 定义同步接口（股票列表、日线行情、周线行情、月线行情等）
- 每个同步接口可配置同步参数（如"交易日"）
- 配置接口调用间隔时间（避免触发数据源限流）
- 配置接口超时时间

### 3. 同步调度管理（DS-003）
- 定时同步（设置每天特定时间自动执行）
- 手动触发同步（立即执行某个任务）
- 调度状态管理（启用/暂停调度任务）

### 4. 同步执行与日志（DS-004）
- 同步任务执行流程控制
- 同步执行日志记录
- 同步历史查询
- 错误处理与重试机制

## 技术架构

### 数据库设计
- `data_sources` - 数据源配置表
- `sync_tasks` - 同步任务配置表
- `sync_schedules` - 同步调度配置表
- `sync_logs` - 同步执行日志表
- `sync_params` - 同步任务参数表

### 数据存储设计
- 同步的行情数据存储到独立的业务表（如 `stocks`、`daily_quotes`、`weekly_quotes`、`monthly_quotes`）

### 后端架构
- 数据源适配器模式（Adapter Pattern）：统一不同数据源的接口
- 同步任务执行器（基于任务队列或后台任务）
- 定时调度器（基于 APScheduler 或 Celery Beat）

### 支持的数据源
| 数据源 | 说明 | 主要数据 |
|--------|------|----------|
| Tushare | 免费/付费的 A 股数据接口 | 股票列表、日线、周线、月线、财务数据 |
| AKShare | 开源财经数据接口 | 股票列表、行情、资金流向 |
| 同花顺(THS) | REST API + API Key（fuyao.aicubes.cn） | 行情K线、财务、估值快照、同花顺指数/板块、特色数据（热榜/龙虎榜/涨停池）|

### 支持的同步数据类型
| 数据类型 | 说明 | Tushare 接口 | 单次限量 | 频率限制 | 积分要求 |
|----------|------|-------------|----------|----------|----------|
| 股票列表 | A 股全部股票基本信息 | `stock_basic` | 6000 行 | 50 次/分钟 | 2000 |
| 日线行情 | 每日 OHLCV 数据（未复权） | `daily` | 6000 行 | 500 次/分钟 | 基础 |
| 周线行情 | 每周 OHLCV 数据 | `weekly` | 6000 行 | - | 2000 |
| 月线行情 | 每月 OHLCV 数据 | `monthly` | 4500 行 | - | 2000 |

> 各接口的字段定义、调用方式详见 **[Tushare 接口技术参考](tushare-api-reference.md)**。

## 验收标准

### 系统级验收
- [ ] 能成功配置 Tushare 数据源并测试连接
- [ ] 能创建多个同步任务并配置参数
- [ ] 定时同步任务能在指定时间自动执行
- [ ] 手动同步能立即触发并返回执行结果
- [ ] 同步的数据正确写入业务表

### 功能级验收
- [ ] 支持配置每个同步任务的调用间隔时间
- [ ] 支持配置每个同步任务的超时时间
- [ ] Token 通过配置文件安全配置
- [ ] 同步日志完整记录每次执行情况
- [ ] 同步失败时有明确的错误信息

### 性能级验收
- [ ] 调用间隔配置生效，不会触发数据源限流
- [ ] 超时配置生效，避免任务长时间挂起
- [ ] 大量数据同步时系统稳定
