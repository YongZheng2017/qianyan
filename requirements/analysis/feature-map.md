# 分析端功能地图

## 功能概述

分析端是面向终端用户的股票分析界面，基于管理端同步的市场数据，提供行情查看、基本面分析和资金趋势分析三大功能。

分析端与数据同步模块的关系：**数据同步模块（DS-001~004）采集数据落库，分析端负责读取并可视化展示**。本模块是数据同步的下游消费方。

## 一级菜单

### 1. 行情（MQ）
查看标的（股票/板块/市场）的 K 线行情，支持日线、周线、月线切换。

### 2. 基本面分析（FA）
查看个股的财务指标、估值、成长性等基本面数据。

### 3. 资金趋势分析（FF）
分析个股/板块/市场的资金流向趋势。

## 技术架构

### 数据来源
分析端**只读取**数据库，不直接调用外部数据源。所有数据由管理端数据同步模块预先采集：

| 分析功能 | 依赖数据表 | 同步状态 |
|----------|------------|----------|
| 行情 - 个股 | `stocks`、`daily_quotes`、`weekly_quotes`、`monthly_quotes` | ✅ 已支持 |
| 行情 - 市场指数 | `index_quotes`（待新增） | ⏳ 需扩展同步（Tushare `index_daily/weekly/monthly`） |
| 行情 - 板块 | 板块成分表 + 聚合行情（待定） | ⏳ 需扩展同步（Tushare 申万板块 或 按 industry 聚合） |
| 基本面分析 | 财务指标表（待新增） | ⏳ 需扩展同步（Tushare `fina_indicator` 等） |
| 资金趋势分析 | 资金流向表（待新增） | ⏳ 需扩展同步（Tushare `moneyflow` 等） |

### 技术栈
- **前端**：Vue3 + ECharts（K线/图表）+ Element Plus
- **后端**：FastAPI（查询接口，只读）
- **数据库**：MySQL（读已同步的业务表）

### API 设计
- 分析端 API：`/api/v1/analysis/*`（独立前缀，区别于管理端 `/admin/*`）
- 认证：JWT Token（分析端用户权限）
- 只读：不修改数据

## 验收标准（系统级）

- [ ] 分析端登录后显示三大一级菜单
- [ ] 行情页面可选择股票/板块/市场并查看日/周/月线
- [ ] 所有展示数据来自数据库（不实时调外部接口）
- [ ] 权限控制：分析端用户只能访问 analysis API
