# FA-001: 基本面分析

## 用户故事

作为投资者，我希望在分析端选择某个股票后，能从**三大报表、四大核心能力、估值水平**三个层面全面查看该公司的基本面和财务指标，并能纵向看历史趋势、横向看行业对比，从而判断这家公司是否值得投资。

## 设计理念

基本面分析的核心是回答三个问题：**公司赚不赚钱？家底厚不厚？股价贵不贵？** 页面围绕这三个问题，用「**分页（Tab）+ 图表 + 指标卡片**」的方式分层展示，让用户从概览到细节逐层深入。

## 页面整体布局

```
┌─────────────────────────────────────────────────────────┐
│ [搜索股票]  平安银行(000001.SZ) 银行 最新价:10.5 +1.2%   │ ← 选股 + 基本信息

├─────────────────────────────────────────────────────────┤
│                                                         │
│                  (当前Tab的内容)                         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## Tab 1：概览（一眼看全貌）

**目的**：用户进入后 3 秒内抓住公司核心面貌。

```
┌─ 核心指标卡片（8个，最新报告期）──────────────────────┐
│  ROE: 12.5%    毛利率: 45%    净利率: 20%    资产负债率: 60%  │
│  营收增长: 15% 净利润增长: 18% PE: 8.5       PB: 0.9         │
└─────────────────────────────────────────────────────────┘
┌─ 最新财报摘要 ─┐  ┌─ 盈利趋势（近8季ROE/净利率折线）─┐
│ 报告期: 2025Q4 │  │      ROE ─── 净利率 ───         │
│ 营收: 1500亿   │  │  12%│         ●─●─●              │
│ 净利润: 300亿  │  │   8%│   ●─●─●                    │
│ 经营现金流: 280│  │     └────────────────            │
└────────────────┘  └─────────────────────────────────┘
┌─ 风险提示条 ───────────────────────────────────────────┐
│ ⚠ 资产负债率 78%（偏高）  ⚠ 经营现金流/净利润 < 0.7   │
└─────────────────────────────────────────────────────────┘
```

- **指标卡片**：高亮显示核心值，附带同比变化箭头（↑↓）
- **风险提示**：自动检测异常指标（负债率>75%、现金流为负、ROE下滑等）并标红提示

## Tab 2：三大报表（看明细）

**目的**：展示利润表、资产负债表、现金流量表的明细数据，支持多报告期对比。

```
[利润表 ▼] [资产负债表] [现金流量表]   报告期: 最近 [8▼] 期
┌──────────────┬────────┬────────┬────────┬────────┐
│ 项目         │ 2025Q4 │ 2025Q3 │ 2025Q2 │ 2025Q1 │ ← 多期横向对比
├──────────────┼────────┼────────┼────────┼────────┤
│ 营业总收入   │ 1500亿 │ 1450亿 │ ...    │ ...    │
│ 营业收入     │ 1480亿 │ ...    │        │        │
│ 营业利润     │  350亿 │ ...    │        │        │
│ 净利润       │  300亿 │  280亿 │ ...    │ ...    │
│ 归母净利润   │  295亿 │ ...    │        │        │
│ 基本EPS      │  1.52  │ ...    │        │        │
│ ...          │        │        │        │        │
└──────────────┴────────┴────────┴────────┴────────┘
[查看完整报表（含raw_data全部字段）]  [导出Excel]
```

- **切换报表**：利润表/资产负债表/现金流量表 三个子标签
- **多期对比**：列=报告期，行=报表科目，支持选最近 N 期（4/8/12）
- **核心科目**：列表展示（从 raw_data 提取），点击行可看趋势小图
- **完整数据**：展开查看 raw_data 中 Tushare 全部 90+/140+ 字段

│         ╱   ╲                  │  │  净利率: 20%            │

│                               │  │  净利润增长: 18%        │
└───────────────────────────────┘  │  EPS增长: 16%           │
                                  │ 【营运能力】            │
┌─ 历史趋势（选指标看多年）─────┐  │  应收周转率: 8.5        │
│  指标: [ROE ▼]  期数: [12▼]   │  │  总资产周转: 0.5        │

- **雷达图**：四维（盈利/成长/营运/偿债），每维综合评分（按行业百分位）
- **指标明细**：分类列出四大能力的具体指标，标注行业均值对比
- **历史趋势**：选任一指标看近 N 期趋势折线，识别改善/恶化

## Tab 4：估值分析（贵不贵）

**目的**：判断当前股价是否合理。

```
┌─ 当前估值（基于最新股价+财报）─────────────────────────┐
│  PE(市盈率): 8.5    行业中位: 7.2    历史5年中位: 7.8   │
│  PB(市净率): 0.9    行业中位: 0.85   历史5年中位: 1.1   │
│  PEG: 0.47 (<1，可能低估)                              │
│  结论提示: 当前PE低于历史中位，PB破净，估值偏低          │
├─────────────────────────────────────────────────────────┤
│  PE历史分位图（近5年）                                  │
│  高估 ┃        ████████░░░░        ┃ 当前(25%分位)      │
│       ┃  ████████████████████     ┃                    │
│  低估 ┃███████████████████████████┃                    │
└─────────────────────────────────────────────────────────┘
┌─ 估值趋势（PE/PB 随时间变化）─────────────────────────┐
│  PE ─── PB ───   （股价月线叠加为背景）                 │
└─────────────────────────────────────────────────────────┘
```

- **PE/PB/PEG**：基于最新收盘价 + 最新 EPS/BPS/增长率 计算
- **历史分位**：当前估值在近5年的百分位位置（纵向看贵不贵）
- **行业对比**：与同行业其他公司估值对比（横向看贵不贵）
- **结论提示**：综合纵向+横向给出"高估/合理/偏低"提示

> ⚠️ 估值依赖：最新股价（`daily_quotes` 最新 close）+ 最新 EPS/BPS（`fin_indicator`）+ 增长率。需已同步该股票的行情和财务数据。

## 指标体系（数据来源映射）

| 维度 | 指标 | 来源 | 说明 |
|------|------|------|------|
| **盈利** | ROE / ROE_WAA / ROA | fin_indicator | `roe` / `roe_waa` / `roa` |
| | 毛利率 / 净利率 | fin_indicator | `grossprofit_margin` / `netprofit_margin` |
| **成长** | 营收增长率 | fin_indicator | `or_yoy` |
| | 净利润增长率 | fin_indicator | `netprofit_yoy` |
| | EPS增长率 | fin_indicator | `basic_eps_yoy` |
| **营运** | 存货周转率 / 应收周转率 | fin_indicator | `inv_turn` / `ar_turn` |
| | 总资产周转率 | fin_indicator | `assets_turn` |
| **偿债** | 流动 / 速动比率 | fin_indicator | `current_ratio` / `quick_ratio` |
| | 资产负债率 | fin_indicator | `debt_to_assets` |
| **利润表** | 营收/净利润/毛利/EPS | fin_income | 核心字段 + raw_data |
| **资产负债** | 总资产/总负债/净资产 | fin_balancesheet | 核心字段 + raw_data |
| **现金流** | 经营/投资/筹资现金流 | fin_cashflow | `n_cashflow_act` 等 |
| **估值(算)** | PE | 实时计算 | 最新close / `eps` |
| | PB | 实时计算 | 最新close / `bps` |
| | PEG | 实时计算 | PE / `netprofit_yoy` |

## API 设计（分析端，只读）

```
# 1. 概览（核心指标 + 最新财报 + 风险提示）
GET /api/v1/analysis/fundamental/overview?ts_code=000001.SZ
→ { stock_info, latest_period, core_indicators[], latest_statement, risk_alerts[] }

# 2. 三大报表（多期）
GET /api/v1/analysis/fundamental/statements?ts_code=000001.SZ&type=income&periods=8
→ { headers[报告期], rows[{科目, 值[]}] }

# 3. 能力指标（四维 + 历史趋势）
GET /api/v1/analysis/fundamental/indicators?ts_code=000001.SZ&periods=12
→ { profitability[], growth[], operation[], solvency[] }

# 4. 估值（PE/PB/PEG + 历史分位 + 行业对比）
GET /api/v1/analysis/fundamental/valuation?ts_code=000001.SZ
→ { pe, pb, peg, industry_median, history_percentile, conclusion }

# 5. 行业对比（同行业各公司指标，用于横向对比）
GET /api/v1/analysis/fundamental/industry-compare?industry=银行&indicator=roe
→ [{ ts_code, name, value }...]
```

## 验收标准

### 功能
- [ ] 搜索选择股票后，4 个 Tab 正确展示对应数据
- [ ] 概览页核心指标卡片显示最新期数据 + 同比
- [ ] 三大报表支持多期对比（列=报告期）
- [ ] 能力分析雷达图四维评分 + 指标明细
- [ ] 估值分析 PE/PB/PEG + 历史分位 + 行业对比
- [ ] 风险提示自动检测异常指标（负债率>75%/现金流为负等）

### 数据
- [ ] 指标数据来自 fin_indicator / fin_income / fin_balancesheet / fin_cashflow
- [ ] 估值基于最新股价（daily_quotes）+ 最新 EPS/BPS 实时计算
- [ ] 行业对比基于 stocks.industry 聚合同行业数据

### 体验
- [ ] 无数据时（未同步财务数据）友好提示，引导去管理端同步
- [ ] 指标值带颜色（优于行业=绿，差于=红）
- [ ] 报表期可切换数量（4/8/12期）
