# 用户管理功能地图

## 功能概述

用户管理模块是系统的核心基础模块，提供用户的身份认证、权限管理和用户信息维护功能。该模块服务于管理端和分析端，确保系统的安全性和用户数据的完整性。

## 核心功能

### 1. 系统初始化
- 系统首次启动时自动创建 admin 用户
- 设置默认密码 123456
- 分配最大权限

### 2. 用户登录
- 管理端登录入口
- 分析端登录入口
- 独立的权限验证

### 3. 用户管理
- 用户列表查看（分页、搜索、筛选）
- 新增用户
- 编辑用户信息
- 修改用户密码

### 4. 分析端菜单
- 根据用户权限动态生成菜单
- 左侧菜单展示
- 菜单导航功能

## 技术架构

### 数据库设计
- users 用户表
- roles 角色表
- permissions 权限表
- user_roles 用户角色关联表
- role_permissions 角色权限关联表

### API 设计
- 统一响应格式
- JWT Token 认证
- 分页查询接口

### 前端架构
- React 组件化开发
- 路由权限控制
- 状态管理
